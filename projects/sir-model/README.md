# Spatial SIR Model with Individual Mobility

An APM348 course project by Max Elinson and Ethan Kharitonov, studying a stochastic SIR epidemic model with individual movement between shared hubs represented by Markov chains.

The report develops state-space lumping and a quotient-chain formulation for analyzing final outbreak-size distributions. Direct computation remained impractical for the studied setting, so the experiments use Monte Carlo simulation with synthetic movement patterns. Results examine hub-specific transmission and sensitivity to initial infection levels.

Max contributed to the model formulation, lumping analysis, and Python simulation code, ran experiments, and analyzed the resulting figures and tables. The report includes the individual contribution statements.
