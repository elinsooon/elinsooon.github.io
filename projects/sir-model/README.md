# Spatial SIR Model with Individual Mobility

This project studies a stochastic SIR epidemic model where individuals move between spatial hubs according to a Markov chain. The model connects epidemic dynamics with mobility structure, allowing outbreak behavior to be compared across different hub networks and movement assumptions.

## Materials

- Full report: `assets/sir-model/APM348_Final_Project.pdf`
- Presentation slides: `assets/sir-model/apm348_final_slides.pdf`

## Technical focus

- Hub-based individual mobility
- Markov chain movement model
- Stochastic SIR simulation
- State-space lumping / quotient chain reduction
- Monte Carlo analysis of outbreak-size distributions

## Resume summary

Built a hub-based stochastic SIR model with individual movement represented as a Markov chain, using state-space lumping and Monte Carlo simulation in Python to quantify outbreak-size distributions and identify high-risk hubs.
