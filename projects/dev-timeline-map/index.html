Toronto Development Timeline

An interactive 3D map combining Toronto development applications, building massing, and selected OpenStreetMap geometry. A year slider controls application overlays and completed building layers.

I built a Python geospatial pipeline to join applications with footprints, classify status, generate as-built layers, and check how completed buildings replace earlier massing. The browser uses MapLibre, deck.gl, and PMTiles to display the resulting geometry.

Proposals appear as wireframes; completed records use solid green massing where available. The map combines 2015 historical and 2025 current massing. Approximate locations, related applications, and estimated heights limit the reconstruction, and application dates do not necessarily indicate construction dates.
